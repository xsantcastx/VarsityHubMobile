# SendGrid Template Export

This folder was generated by `scripts/exportForSendGrid.js`.
Upload each HTML file into its matching SendGrid Dynamic Template.

## Steps to upload
1) Open SendGrid → Dynamic Templates
2) Pick the template by name
3) Click "Edit" → replace HTML with the generated file
4) Set the subject (already in the file header)
5) Save & publish
