```properties
reactNativeArchitectures=armeabi-v7a,arm64-v8a,x86,x86_64

# Individual APKs per architecture:
# ARM64 (arm64-v8a)    - Primary (85% of market)
```

**APK Size Impact by Architecture:**
- **arm64-v8a:** ~45MB (primary)
- **armeabi-v7a:** ~42MB (legacy)

- **Universal APK:** ~180MB (all architectures bundled)

**Recommendation:** Use App Bundle (`.aab`) for Google Play Store
- Automatic per-device APK generation
- Reduced user download size (~30-40% smaller)
