## Rollback Plan (If needed)

If critical issues found during review:

1. **Immediately notify Apple** through TestFlight/App Store Connect
2. **Create hotfix branch**: `hotfix/v1.0.1-[issue]`
3. **Apply minimal fix** (do not major refactor)
4. **Build & resubmit**: `eas build && eas submit`
5. **Maintain version 1.0.1** (don't jump to 1.0.2)
