# Email Templates Checklist

This checklist enumerates all SendGrid dynamic template env vars used by the backend. Configure these per environment.

Recommended: In production, set `EMAIL_STRICT_TEMPLATES=1` and ensure all non-deprecated templates are present. Optionally override required keys via `EMAIL_REQUIRED_TEMPLATES` (comma-separated template keys).

- `SENDGRID_PASSWORD_RESET_TEMPLATE_ID`
- `SENDGRID_PASSWORD_CHANGED_TEMPLATE_ID`
- `SENDGRID_ACCOUNT_RECOVERY_TEMPLATE_ID`

## Config Flags
- `EMAIL_PROVIDER` (sendgrid|mock)
- `SENDGRID_API_KEY` (required for sendgrid provider)
- `EMAIL_STRICT_TEMPLATES` ("1" to enforce in production)
- `EMAIL_REQUIRED_TEMPLATES` (comma-separated list of template keys to require)
- `EMAIL_FROM` or `FROM_EMAIL`
- `APP_BASE_URL`

Notes:
- When providing snake_cased keys in template data, the system auto-adds camelCase variants.
- If provider is `mock`, emails are written to `.outbox/` for inspection.
