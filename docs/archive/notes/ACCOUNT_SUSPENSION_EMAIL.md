# Account Suspension Email (45-Day Ban)

This guide documents the implementation and preview of the "Account Suspended" email, used when a violator is banned for 45 days.

## Database Changes

Add suspension fields to your `users` table:

```sql
ALTER TABLE users
  ADD COLUMN is_suspended BOOLEAN DEFAULT FALSE,
  ADD COLUMN suspension_end_date TIMESTAMP,
  ADD COLUMN suspension_reason TEXT;
```

Middleware suggestion:

- Block suspended users from logging in: if `is_suspended = TRUE` and `suspension_end_date > NOW()`, deny auth and return `until`.
- Auto-reinstate with a daily cron: when `NOW() >= suspension_end_date`, set `is_suspended = FALSE` and clear reason.

## Appeal Flow (Email Button)

All appeals go to `customerservice@varsityhub.app` via a prefilled `mailto:` link generated by the backend.

Suggested subject/body format:

```
Subject: Appeal Suspension for Report #12345

Hi VarsityHub Team,

I am appealing the 45–day suspension for Report #12345.

Violation Type: Harassment
Suspension Date: December 15, 2025
Reinstatement Date: January 29, 2026

Reason for Appeal:
[User types their explanation here]

Thank you,
John Doe
```

## Tips

- Calculate reinstatement date automatically: `reinstatement = addDays(suspensionDate, 45)`.
- Add audit logging for all report decisions and appeals.
- Keep dynamic data snake_case in backend email payloads for SendGrid compatibility.

## Backend Integration

- In `server/src/routes/adminReports.ts`, ensure that for `dismissed` policy violations, a 45-day suspension is applied and `appeal_url` is a mailto link.
- In `server/src/lib/email.ts`, the `sendReportResolutionEmail()` function should pass `appeal_url` through to your templates.
