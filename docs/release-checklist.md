# Pre-release QA Checklist

- **Backend health**
  - `/health` returns OK.
  - `/search` returns users/teams/orgs/games/posts/events/highlights; follow/unfollow works for users, teams, orgs.
- **Auth**
  - Email/Apple/Google login on device; password reset; logout.
  - Blocked users list works; block/unblock by username/email.
- **Navigation**
  - Tabs and deep links open: user/team/org profile, event detail, post detail, highlights.
- **Forms**
  - Report Abuse (with screenshot), Create/Pitch Event, RSVP, Follow/Unfollow, Block user, Settings edits save without errors.
- **Media**
  - Image uploads succeed via `/uploads`; screenshot attach works; highlight media renders; no crashes on missing media.
- **Search**
  - Discover search shows users/teams/orgs/games/posts/highlights/events; navigation from results works.
- **Theming**
  - Light/dark readable; no duplicate headers (Settings fixed).
- **Device build**
  - iOS device build succeeds (pods/codegen clean); app launches without redboxes; push/token init doesn’t crash if unavailable.
- **Performance**
  - Scroll feeds/highlights without jank; Metro logs clean; no runaway re-renders.
- **Security**
  - Snyk scan clean; API secrets not bundled; rate limits intact for auth/abuse/report.
