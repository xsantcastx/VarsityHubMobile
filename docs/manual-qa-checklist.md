# VarsityHubMobile Manual QA Checklist

## 1. Onboarding

- [ ] Register as Fan, Coach, and Organization
- [ ] Complete onboarding for each role (username, DOB, ZIP, plan selection, etc.)
- [ ] Verify onboarding completion sets correct permissions and role

## 2. Event System

- [ ] Fan can request to host event
- [ ] Coach/Organization sees pending event requests in settings
- [ ] Coach/Organization can approve/reject event requests
- [ ] Approved events appear in event lists/maps

## 3. Google Maps

- [ ] Location autocomplete works in event forms
- [ ] Event pins display on map
- [ ] Map interaction (zoom, pan, select event) works

## 4. Banner Ad System

- [ ] Banner ads display on main screens
- [ ] Admin can create/manage ads
- [ ] Ad click-through works

## 5. Notifications

- [ ] Push notification registration works
- [ ] In-app notifications display for event approvals, etc.

## 6. Settings & Permissions

- [ ] Profile edit, password reset, notification toggles work
- [ ] Only coaches/orgs can approve events
- [ ] Only admins see admin panels
- [ ] Data privacy: no sensitive data leaks in logs/UI

## 7. General

- [ ] Test on iOS and Android
- [ ] Test with network loss, invalid input, expired sessions
- [ ] All major screens/components render without error

**Result:**

- Mark each item as you test. Report any failures or unexpected behavior.
