# VarsityHub v1.0.2 — Runtime Test Checklist

Run on a real device or simulator via `npx expo run:ios`. Each test should be tapped through manually. Mark PASS/FAIL/BLOCKED.

---

## Pre-Flight

- [ ] `npx expo run:ios` builds and launches without crash
- [ ] `npx expo start --web --clear` loads `localhost:8081` without 500
- [ ] Server is reachable (staging or local with `DATABASE_URL` + `JWT_SECRET`)

## 1. Coach Onboarding — New Signup

**Entry:** Launch app → "Sign Up" button

| #   | Step                                          | Expected                                                      | Result |
| --- | --------------------------------------------- | ------------------------------------------------------------- | ------ |
| 1.1 | Tap "Sign Up", enter email/password, submit   | Account created, email verification screen appears            |        |
| 1.2 | Verify email (check inbox, tap link)          | Returns to app, routes to onboarding step-1 (role select)     |        |
| 1.3 | Select "Coach" role, confirm 18+ gate         | Routes to step-2 (basic info)                                 |        |
| 1.4 | Fill name, profile photo, location, zip code  | Fields save, "Next" becomes active                            |        |
| 1.5 | Tap "Next" → step-3 (league/org)              | Organization creation or join screen appears                  |        |
| 1.6 | Create new organization (enter name)          | Org created, routes to coach agreement                        |        |
| 1.7 | Read and accept coach agreement               | `coach_agreement_accepted_at` set, routes to pending-approval |        |
| 1.8 | Pending approval screen shows polling state   | Screen displays "Waiting for approval" with status updates    |        |
| 1.9 | (Admin approves coach from org owner account) | Pending screen updates, user gains full access                |        |

**Verify after approval:**

- [ ] Feed loads
- [ ] "Create Team" button works
- [ ] "Create Post" button works
- [ ] No `COACH_AGREEMENT_REQUIRED` or `APPROVAL_REQUIRED` errors in console
